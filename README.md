# warGame

Стратегия с конструктором из трёх независимых компонентов: ходовая, корпус и верхний модуль.

## Карта Alpha и первый комплект

[Открыть демо](http://127.0.0.1:8766/demo/) · [Управление](demo/README.md) · [Полная карта и материалы](assets/maps/alpha/README.md) · [Игровые GLB](assets/vehicles/README.md)

Карта размером 4064 × 4064 м построена по исходной сетке Alpha. Сохранены ровные площадки, округлены кромки плато. Двенадцать слоёв поверхности и четыре набора PBR-карт дают охристый грунт, каменистые склоны и старый асфальт. Единая дорожная сеть из 19 ветвей проходит по долинам к воротам будущих баз. Полный тур длиной 41,7 км посещает 12 точек и все ветви; доступны миникарта и ускорение просмотра. Пыль стелется в низинах и рассеивается за машиной.

Локальный запуск: `python tools/serve.py`, затем открыть ссылку демо выше. Сервер отключает кэш ресурсов во время ревью.

[Мастерская диалогов](http://127.0.0.1:8766/dialogues/) работает на том же сервере. Здесь доступны миссии, сюжетные и ситуационные реплики, старый сценарий и портреты персонажей. Можно прослушивать отдельные записи или весь диалог, менять текст, порядок, условия, паузы, аудио и изображения. Правки автоматически сохраняются в `docs/campaign/dialogue-drafts/<mission-id>/draft.json`; загруженные файлы — в соседней папке `media`. Игра продолжает использовать свой сценарий до переноса согласованных правок. Значок скачивания собирает ZIP: `snapshot.json`, читаемый `dialogues.md` и все связанные записи и портреты. При одновременной правке в двух вкладках редактор сохраняет локальную копию и сообщает о конфликте.

Вкладка [«Динамический эфир»](http://127.0.0.1:8766/dialogues/#dynamic) заменяет «По ситуации»: 225 конфигураций, фильтр реальной поддержки, масштабы 1/5/20, графы реплик, голоса и симулятор. Здесь черновик сохраняется значком дискеты, а публикация отдельно применяется при следующем открытии игры. Прежние 25 сцен и записи сохранены; их можно открыть из соответствующей ситуации. [Устройство, покрытие и проверки](docs/campaign/dynamic-radio.md) · [Лист записи на 6 дополнительных голосов](docs/campaign/radio-recording-plan.txt). Проверки: `npm run check:radio` и `npm run check:radio:browser`.

В игру перенесён слепок №70 до этапа III «Завод и боевые „Буханки“» включительно: 30 реплик, 24 загруженные записи. Применённый сценарий хранится в `assets/campaign/alpha/mission01/reviewed-dialogue.json`, записи — в `recordings/reviewed/`; последующие изменения черновика не меняют эту версию. Для переноса согласованного участка: `python tools/apply-dialogue-draft.py --through-scene r10 --revision <номер-слепка>`. Скрипт сверяет версию и файлы, сохраняет исходное аудио и отказывается применять незаменённые временные голоса. Старые файлы остаются доступными архивным сценариям. [Отчёт о переносе](docs/campaign/alpha/voice/applied-stage-iii.json) отмечает также реплики, текст которых менялся после загрузки записи.

Начавшийся диалог звучит до конца во время боя. О нападении сообщает существующий мигающий маркер на миникарте; срочные сюжетные сообщения ждут свободного эфира. Между сценами выдерживается не менее двух секунд тишины, а внутри разговора используются заданные паузы реплик. Авторемонт строителей относится только к готовым постройкам; машины обслуживаются на заводах. Старые задания строителей на ремонт машин снимаются при загрузке сохранения.

C01 «Двор» и B01 «Буханка» подготовлены независимыми GLB с тремя LOD. Работают руление, качание, свет, стрельба временного U01 и разборка. Масштаб сборки на карте согласован с полосой дороги; студия осмотра остаётся метрической. [Манифест моделей](assets/vehicles/manifest.json) ожидает визуального одобрения перед работой над оружием и каталогом образцов.

## Подготовка кампании

[Играть первую миссию](http://127.0.0.1:8766/campaign/) · [Командирский УАЗ по модулям](http://127.0.0.1:8766/campaign/command-review.html) · [Архивный сюжетный фильм](http://127.0.0.1:8766/campaign/watch.html) · [Состояние реализации](docs/campaign/implementation.md)

Первая миссия начинается с трёх боевых «Буханок» и двух строителей. Игровые события сопровождает короткое текстовое радио, которое можно отключить. Из найденных и исследованных технологий собираются проекты в 3D-конструкторе, а завод выпускает их по очереди. Иллюстрированный фильм собирается отдельно командой `npm run export:cinematics`.

Строитель C01 + B01 + U25 поднимает постройку слоями с помощью подвижного оптического проектора. Шесть моделей зданий и их размерные спецификации хранятся в [каталоге зданий](assets/blueprints/buildings/manifest.json). Завод, НИИ и электростанция сделаны по [промышленному атласу](references/buildings/industrial-atlas.png).

Размерные GLB — заготовки; игровые GLB первого комплекта находятся отдельно в `assets/vehicles`.

## Проверка

`npm run check:assets` проверяет 46 спецификаций; `npm run check:models` — шесть игровых GLB; `npm run check:map` — исходный рельеф, стыки и ресурсы; `npm run check:roads` — проходимость всего тура. Браузерные проверки: `check:terrain`, `check:driving`, `check:demo`. Средства пересборки находятся в `tools`.
