# Итоги операции и холм памяти

Экран открывается при победе/поражении и после загрузки завершённой миссии.
При включённом радио победный разговор сначала доигрывается с портретами и
субтитрами на карте; итоги уже доступны через меню. При выключенном радио и
при поражении экран открывается сразу.
Из первой миссии можно продолжить во вторую с прежней армией. Вернуться к
итогам можно из меню операции. После второй миссии продолжения не выдумывается.
Кнопки используют имеющиеся свободные иконки игры и подсказки, без рамок.

На холме рисуется ровно один православный восьмиконечный деревянный крест
с компактным круглым земляным холмиком на запись погибшего. Мелкие таблички
убраны. Наведение, нажатие или выбор стрелками показывает рядом с могилой имя,
позывной, звание на момент гибели, миссию гибели и личный счёт. Технический ID
машины в подсказке не показывается. На фоне нет нарисованных могил.
Сейчас все кресты одинаковые; `memorialMarker(rank, styles)` позволяет отдельно
подключить варианты для званий, не меняя сохранение.

Владелец одобрил текущий спрайт для рядового. Материалы, генерация, лицензии
шрифтов и анимация описаны в [grave-private-v2.md](../../../assets/campaign/personnel/grave-private-v2.md).
Затемнение, насыщенность, прозрачность и мягкость зависят от глубины. Дымка,
пыль, трава, ткань флага и вороны движутся в пределах сцены. Три дальние птицы
одного физического размера проецируются по глубине: скорость и размах крыльев
согласованы с перспективой, планирование сменяется короткими сериями взмахов.
Флаг — отдельное прозрачное красное полотнище с черепом в шестерне, как в меню.
Деформируется только его ткань; древко и небо остаются неподвижными.
На экране памяти зациклен предоставленный владельцем трек «The Red Banner's
Last Stand», с плавным переходом и общей настройкой звука.

В бою отображаются тип, буквочисловое обозначение и позывной. Пока один
именной боец на машину; `config.units[kind].crewSize` поддерживает экипажи из
нескольких человек. В таком случае совместное уничтожение засчитывается каждому
члену экипажа, а общий счёт миссии увеличивается один раз. Противник — отдельная
вражеская сущность (пехота или машина), сооружения считаются отдельно. Собственные
потери и дружественный огонь не увеличивают число уничтоженных противников.

Архив бойцов находится в `state.campaign.personnel`, переживает удаление
обломков, переход между миссиями и загрузку. Источник горения и летящего снаряда
опознаётся по сохранённому ID даже после гибели стрелявшего. Записи итогов
замораживаются в конце миссии. Загрузка более раннего сохранения возвращает
именно его историю — будущие погибшие в неё не подмешиваются.

Старые сохранения не содержат достоверной истории убитых и исчезнувших обломков:
счёт начинается после обновления, неполнота явно показана. Нельзя задним числом
восстановить имена и число погибших, которых старое сохранение не записывало.

Звания: все 20 войсковых и 19 корабельных записей. Для нынешних сухопутных
подразделений используется войсковая шкала, начальное звание — рядовой.
Автоматические повышения пока не вводились; изменение через `setPersonnelRank`
проверяет справочник. Рядовой без лычек; ефрейторы/сержанты с прямыми нашивками;
прапорщики/офицеры с пятиконечными звёздами в соответствующем расположении.
Векторная символика упрощена для игрового размера.

Источники: [53-ФЗ, статья 46](https://www.consultant.ru/document/cons_doc_LAW_18260/9bf0f600c3225937651f53299c73a4dd167a819e/),
[Указ №293, приложение 3](https://base.garant.ru/197700/3e22e51c74db8e0b182fad67b502e640/).
Источники и ограничения частот имён: [names-data.md](../../../assets/campaign/personnel/names-data.md).

Проверки: `node tools/check-personnel.mjs`, `node tools/check-m02.mjs`,
`node tools/check-personnel-browser.mjs`. Браузерные снимки в
`campaign/previews/personnel/` используют специально подготовленную тестовую
партию, а не сохранение владельца. В основную ветку изменения не слиты.
