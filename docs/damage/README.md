Ручная проверка: запустить `python tools/serve.py`, открыть [кампанию с панелью повреждений](http://127.0.0.1:8766/campaign/?damage=1). Shift+клик — контакт по поверхности; панель позволяет выбирать деталь, тип воздействия, дистанцию и уничтожение. Состояние входит в обычный save/load.

Реализованы локальные следы, накапливаемая GPU-деформация кузова, подготовленные отделяемые детали, ограниченные обломки, индивидуальные останки, материальные профили и LOD. Завод, НИИ, электростанция и башни имеют повреждаемые окна/внешние элементы. Подготовленная геометрия общая, состояние каждого объекта независимо.

Двери и капот B01 не являются отдельными деталями; окна лежат поверх сплошной основы. Их полноценный отрыв/проёмы, интерьеры и произвольное дробление бетонных стен требуют подготовки моделей. Shader-перфорация не является новым физическим тоннелем. Эти ограничения не скрываются за состоянием в логах: доступные эффекты отображаются реальным renderer и проверяются браузером.

Команды: `npm run check:damage`, `npm run check:damage:browser`, `npm run bench:damage`. У проекта нет общего bundler/build для приложения: ES-модули загружаются напрямую. Проверка загрузки/шейдеров выполняется браузерным тестом, GLB — `npm run check:models`, существующие игровые механики — `npm run check:mission`.
