# Фоновая музыка

- `wasteland-menu.mp3` — «Wasteland Menu», предоставлен владельцем проекта 9 ноября 2026 года. Исходный MP3 сохранён без перекодирования. Полностью скачивается параллельно с подготовкой мира и шейдеров; картинка меню появляется после готовности музыки к воспроизведению. Играет по кругу только в главном меню; выключается общей кнопкой звука и при переходе в игру. Если браузер блокирует автозапуск, включается после первого нажатия в меню.
- `abandoned-technology.mp3` — «Abandoned Technology», предоставлен владельцем проекта 7 ноября 2026 года. Исходный MP3 сохранён без перекодирования.
- В кампании трек зациклен, плавно включается и приглушается на время радиосвязи и реплик юнитов. Общая кнопка звука приостанавливает музыку; повторное включение продолжает воспроизведение с прежнего места.
