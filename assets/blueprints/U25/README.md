# U25 «Строитель», класс S

Инженерная заготовка отдельного верхнего модуля. Используется в сборке C01 + B01 + U25. Художественный референс и окончательная детализация ещё не утверждены. U24 «Мастер» остаётся отдельной средней ремонтной установкой.

Транспортный размерный шаблон: длина 1900 мм, ширина 1300 мм, высота 1250 мм. Нижний фланец Ø900 × 80 мм, начало координат в центре нижней плоскости; оси +X вправо, +Y вперёд, +Z вверх. Художественная геометрия должна вписываться в шаблон. GLB использует метры и стандартную ось Y вверх.

Фланец совмещается с `upper_mount` B01 без изменения масштаба. В состав U25 не входят корпус, колёса, подвеска или арки. Рабочий объём и ограничения каждого узла заданы в [module.json](module.json), три вида — в [dimensions.svg](dimensions.svg), размерный объём — в [blockout.glb](blockout.glb).

Движения: остановка машины → подъём основания → раскрытие локтя → выдвижение телескопа → ориентация головки. При сворачивании порядок обратный. Поворот ограничен ±150° из-за кабелей. Сварка и искры действуют только во время работы; рабочий фонарь включается при развёртывании. Постоянного свечения всей модели нет.

[Посадка, разборка и рабочий цикл в браузере](http://127.0.0.1:8766/campaign/builder.html). Это проверка механики, а не готовая художественная модель. Каталог утверждённых игровых образцов ею автоматически не расширяется.
