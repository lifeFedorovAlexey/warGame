# Огнемёт для «Альфы»

Верхний модуль `mission-flamer` для сборки C01 + B01. В миссии и конструкторе используется один и тот же GLB. Старые проекты сохраняют прежний идентификатор. Геометрия разработана для кампании на штатном интерфейсе S. Модуль U04 «Резак» остаётся отдельной лёгкой пушкой из каталога.

| Параметр | Значение |
| --- | --- |
| Габарит в нулевой позе | 1032 × 1774 × 630 мм |
| Фланец | Ø900 × 80 мм |
| Оси | +X вправо, +Y вперёд, +Z вверх |
| `mount` | (0, 0, 0) мм, нижняя плоскость фланца |
| `turret_yaw` | (0, 0, 80) мм, поворот установки вокруг Z |
| `equipment_pitch` | (0, 181, 422) мм, подъём сопла вокруг X от −12,6° до +32,1° |
| `fx_muzzle` | (0, 1007, 422) мм, начало пламени в нулевой позе |
| Геометрия | 2016 треугольников |

Сопло полое, установка и сопло вращаются независимо. Видимый запальник включается только на время атаки. Струя, угли и дым создаются игровым движком.

Исходник модели находится в `campaign/flamer-module.js`. Экспорт и проверка glTF выполняются командой `node tools/export-field-flamer.cjs` при запущенном локальном сервере.
