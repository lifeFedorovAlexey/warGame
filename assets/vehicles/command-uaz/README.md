# Командирский УАЗ

Самостоятельный комплект для осмотра. Ходовая, кузов и радиоблок лежат в отдельных GLB. [Стенд сборки и разборки](http://127.0.0.1:8766/campaign/command-review.html)

| Компонент | Длина × ширина × высота, мм | Треугольники | Модель |
| --- | ---: | ---: | --- |
| Ходовая C-CMD | 3640 × 1858 × 1050 | 1020 | [C-CMD-lod0.glb](C-CMD/C-CMD-lod0.glb) |
| Кузов B-CMD | 4365 × 1880 × 1395 | 856 | [B-CMD-lod0.glb](B-CMD/B-CMD-lod0.glb) |
| Радиоблок R-CMD | 262 × 100 × 1491 | 164 | [R-CMD-lod0.glb](R-CMD/R-CMD-lod0.glb) |

Габарит сборки 4365 × 1880 × 3661 мм. Размеры округлены до миллиметра по вершинам геометрии. GLB использует метры и Y вверх. Исходные оси проекта +X вправо, +Y вперёд, +Z вверх. Для просмотра в сцене с Z вверх поверните внешнюю обёртку GLB на +90° вокруг X.

## Посадка кузова

Центр `body_mount` ходовой расположен на высоте 1050 мм. У кузова `mount` и нижние контактные поверхности четырёх подушек лежат в локальной плоскости Z=0. Юбки и бамперы выступают ниже этой плоскости по краям. Каждая подушка имеет размер 180 × 180 мм и опирается на поперечину рамы.

| Точка | C-CMD, мм | B-CMD, мм |
| --- | --- | --- |
| Центр стыка | 0, 0, 1050 | 0, 0, 0 |
| `pad_FL` | −650, 1450, 1050 | −650, 1450, 0 |
| `pad_FR` | 650, 1450, 1050 | 650, 1450, 0 |
| `pad_RL` | −650, −1450, 1050 | −650, −1450, 0 |
| `pad_RR` | 650, −1450, 1050 | 650, −1450, 0 |

Совместимость с классом S относится к этому шаблону крепления. Для сочетаний с другой ходовой отдельно проверяются габариты руления, юбок и бамперов. [Общий стандарт](../../../references/standards.md)

## Посадка радио

`radio_mount` находится на кузове в точке (−720, −1760, 1120) мм относительно его монтажного нуля. В сборке высота контакта составляет 2170 мм. У блока `mount` расположен в центре нижней плоскости основания. Пятка Ø100 мм садится в гнездо CMD-RF-100 с площадкой Ø114 мм, подогнанной по скату крыши. Этот приборный интерфейс рассчитан на R-CMD. Кольцо Ø900 относится к другому типу верхних модулей.

## Подвижные узлы и проверка

Колёса вращаются по X, передние кулаки поворачиваются по Z. Узел `antenna_flex` позволяет дать упругую качку хлысту при неподвижном основании. На стенде кнопка «Движение узлов» показывает эти движения. Передние фары и задние габариты имеют светящиеся материалы.

Сборка проверена после повторного импорта всех трёх GLB. Ошибка совмещения шести якорей составила 0 мм. В 25 точках проверены реальные контактные грани, максимальная погрешность составила 0,000048 мм. Khronos glTF Validator подтвердил 0 ошибок и 0 предупреждений у каждого файла.
