# Фоновая музыка

- `wasteland-menu.mp3` — «Wasteland Menu», предоставлен владельцем проекта 9 ноября 2026 года. Исходный MP3 сохранён без перекодирования. Полностью скачивается параллельно с подготовкой мира и шейдеров; при включённом звуке картинка меню появляется только после фактического начала воспроизведения. Если браузер блокирует автозапуск, готовый загрузчик предлагает одно нажатие для входа со звуком. При сохранённой настройке «звук выключен» меню открывается сразу без музыки. Трек играет по кругу только в главном меню и останавливается при переходе в игру.
- `abandoned-technology.mp3` — «Abandoned Technology», предоставлен владельцем проекта 7 ноября 2026 года. Исходный MP3 сохранён без перекодирования.
- В кампании трек зациклен, плавно включается и приглушается на время радиосвязи и реплик юнитов. Общая кнопка звука приостанавливает музыку; повторное включение продолжает воспроизведение с прежнего места.

- `memorial-red-banner.mp3` — «The Red Banner's Last Stand», предоставлен владельцем 10 ноября 2026 года. Исходный MP3 скопирован без перекодирования, SHA-256 `44525706528b1e62a41c7c00ec96aad83549a5f35db26b9916e9d91089c1b64b`. Играет по кругу только на экране памяти, плавно заменяет обычную музыку кампании и подчиняется общей настройке звука. При закрытии итогов затихает и приостанавливается.
