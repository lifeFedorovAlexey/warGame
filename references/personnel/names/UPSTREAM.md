# Имена — открытый датасет русских имён от НЭН

**1551 имя** (809 мужских и 742 женских) с происхождением, значением, редакционной справкой, краткими и международными формами и оценкой популярности по открытым данным московских ЗАГС.

Датасет собран и вычитан редакцией журнала для родителей [НЭН — «Нет, это нормально»](https://n-e-n.ru/). Живая версия каталога с подбором имени по отчеству: **[n-e-n.ru/imena](https://n-e-n.ru/imena/)**.

## Файлы

| Файл | Формат |
|---|---|
| [`data/names.json`](data/names.json) | JSON, массив объектов |
| [`data/names.csv`](data/names.csv) | CSV (UTF-8 с BOM, разделитель — запятая; списки внутри поля — через `; `) |

## Схема

| Поле | Тип | Описание |
|---|---|---|
| `name` | string | Имя («Александр») |
| `gender` | `m` \| `f` | Пол. Имя, встречающееся в обоих списках, помечено тегом `унисекс` |
| `slug` | string | Стабильный идентификатор, совпадает с URL страницы имени |
| `url` | string | Страница имени на n-e-n.ru с полной справкой |
| `origin` | string | Происхождение («древнегреческое») |
| `meaning` | string | Краткое значение (до 110 символов) |
| `about` | string | Справка об имени: этимология и история, без эзотерики и «характера по имени» |
| `short_forms` | string[] | Краткие/уменьшительные формы («Саша», «Шура»…) |
| `international_forms` | string[] | Международные аналоги, если есть |
| `first_letter` | string | Первая буква (для алфавитных указателей) |
| `letters_count` | number | Число букв |
| `popularity_place` | number | Место по частоте среди новорождённых (открытые данные московских ЗАГС, оба пола вперемешку: 1 = самое частое) |
| `popularity_bucket` | `top` \| `popular` \| `medium` \| `rare` | Корзина популярности (96 / 259 / 485 / 711 имён) |
| `tags` | string[] | `классика`, `редкое`, `короткое`, `унисекс` |

## Методология

- **Популярность** — по открытым данным управления ЗАГС Москвы о именах новорождённых за последние годы. Место (`popularity_place`) — относительный ранг внутри этого свода, не абсолютное число регистраций.
- **Значения и справки** — редакция НЭН: сплошная вычитка всех 1551 имени, из справок сознательно убраны астрология, «судьба» и «характер по имени» — только этимология, история и формы.
- Датасет — снимок каталога сервиса «Имена»; живая версия на [n-e-n.ru/imena](https://n-e-n.ru/imena/) может быть свежее.

## Примеры

**Python / pandas**

```python
import pandas as pd
df = pd.read_csv("data/names.csv")
df[df.tags.str.contains("редкое", na=False) & (df.gender == "f")].head(10)
```

**JavaScript**

```js
const names = require("./data/names.json");
const unisex = names.filter(n => n.tags.includes("унисекс"));
```
