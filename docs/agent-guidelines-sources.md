# Источники правил для игровых агентов

Проверено 11 ноября 2026 года. Правила в корневом `AGENTS.md` сформулированы заново для warGame, а не скопированы целиком; требования владельца имеют приоритет. Популярность проекта не доказывает качество отдельных правил.

| Источник | Применённые идеи | Оценка и ограничения |
| --- | --- | --- |
| [Three.js Game Skills — gameplay](https://github.com/majidmanzarpour/threejs-game-skills/blob/main/skills/threejs-gameplay-systems/SKILL.md), [профилирование](https://github.com/majidmanzarpour/threejs-game-skills/blob/main/skills/threejs-debug-profiler/SKILL.md), [проверка](https://github.com/majidmanzarpour/threejs-game-skills/blob/main/skills/threejs-qa-release/SKILL.md) | Играбельный результат, воспроизведение, замеры до и после, настоящая игра и проверка поведения на целевых экранах. | На дату проверки GitHub показывал 2791 звезду и 279 форков. Набор относится к Three.js; предложенный там стек и физический движок не навязываются проекту. |
| [Awesome GameDev Agent Skills — производительность](https://github.com/gamedev-skills/awesome-gamedev-agent-skills/blob/main/skills/disciplines/performance-optimization/SKILL.md) | Искать узкое место измерениями, различать CPU и GPU, сравнивать одинаковые сцены и учитывать пики времени кадра. | GitHub показывал 8331 звезду и 826 форков. Есть [публичная критика формата набора](https://github.com/gamedev-skills/awesome-gamedev-agent-skills/issues/2); независимой проверки пользы каждого правила не найдено. Советы для других движков и обязательное отключение синхронизации не перенесены. |
| [Recoil Engine — инструкции агентов](https://github.com/beyond-all-reason/RecoilEngine/blob/master/AGENTS.md) | Использовать практики и проверки действующего RTS-проекта с большим числом объектов. | GitHub показывал 733 звезды и 327 форков. Проект использует C++, поэтому его команды сборки и правила конкретного движка к warGame не применяются. |
| [Open Realm — инструкции агентов](https://github.com/corepunch/open-realm/blob/main/AGENTS.md) | Учитывать специфику RTS: массовое управление, маршруты, строительство и сохранение полезных результатов диагностики. | GitHub показывал 394 звезды и 56 форков. Правила чужой архитектуры, кодовая база и требования к обратной разработке не переносятся. |

Звёзды и форки показывают интерес к репозиторию, а не отзывы об успешности применения правил в нашей игре. Для этого проекта правила проверяются на практике и корректируются по замечаниям владельца.
