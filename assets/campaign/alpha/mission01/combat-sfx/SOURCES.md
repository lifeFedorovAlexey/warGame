# Боевые звуки

Исходники опубликованы под [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). Файлы собраны из публичных HQ-превью с обрезкой, эквализацией, короткими затуханиями и выравниванием пиков. Игровой формат Ogg Opus, моно, 48 кГц.

| Игровой файл | Источник | Обработка |
| --- | --- | --- |
| `mg-burst.ogg` | [barryshamir · Machine gun firing](https://freesound.org/people/barryshamir/sounds/834242/), запись на стрельбище | Очередь из трёх выстрелов на 0,804–1,190 с. |
| `flame-roar.ogg` | [SyntaxSeed · Gas Torch Burn](https://freesound.org/people/SyntaxSeed/sounds/244230/), запись газовой горелки | Начало горения на 0,064–0,560 с, замедлено до 80%. |
| `armor-hit.ogg` | [dslrguide · Metal Hit Clang](https://freesound.org/people/dslrguide/sounds/321481/), удар по стали | Участок 0,023–0,254 с с коротким металлическим хвостом. |
| `structure-hit.ogg` | [iwanPlays · Bricks/Stones/Rocks/Gravel Falling](https://freesound.org/people/iwanPlays/sounds/567249/) | Участок 0,009–0,263 с для попаданий в постройки и грунт. |
| `debris-fall.ogg` | [iwanPlays · Bricks/Stones/Rocks/Gravel Falling](https://freesound.org/people/iwanPlays/sounds/567249/) | Участок 0,435–1,455 с, замедлен до 78% для осыпания обломков. |

В записи iwanPlays использованы [adamgryu · Rocks.wav](https://freesound.org/s/336023/), [AlanCat · rockfall2a.wav](https://freesound.org/s/389303/) и [spookymodem · Falling Rock.wav](https://freesound.org/s/202098/).
