# Имена бойцов

Данные: [НЭН — сервис «Имена»](https://n-e-n.ru/imena/).
Словарь: [mdanina/nen-imena-dataset](https://github.com/mdanina/nen-imena-dataset),
CC BY 4.0. Использованы написание, пол, происхождение и ссылка; редакционные
описания не включены в игровой каталог. Имена нормализованы, дубли объединены.
Полный исходник и текст лицензии: `references/personnel/names/`.

Наблюдаемая частота: [RussianNames / Иван Бегтин](https://github.com/datacoon/russiannames),
`data/parquet/names.parquet`, агрегированные счётчики публичных реестров.
[Карточка издателя](https://data.apicrafter.ru/packages/russiannames) датирует
публикацию 2019 годом и указывает CC-BY-SA; репозиторий содержит BSD-3-Clause.
Оба указания и исходная лицензия сохранены. Это не перепись населения 2026 года,
не частота имён во всём мире и не рейтинг новорождённых.

`names.js` — производный каталог со ссылками, наблюдаемым числом, рангом,
игровым весом и SHA-256 исходников. Для имён без наблюдений число/ранг остаются
`null`; минимальный игровой вес 1 позволяет им встречаться. Частоты суммируются
при нормализации регистра и ё/е. Названия не повторяются в кампании; после
исчерпания списка добавляются отчества. Позывные созданы для проекта отдельно,
без внешнего словаря, и не используют генератор случайных чисел боя.

Воспроизведение из сохранённых исходников:

```powershell
python -m pip install --target tools/.runtime-names duckdb
python tools/build-personnel-names.py
```

Человекочитаемые файлы: `docs/campaign/personnel/names-alphabetical.txt`,
`names-ranked.txt`, `names-ranked.csv`. Исходный список по алфавиту сохраняет
1548 отдельных написаний; игровой каталог объединяет также варианты ё/е.
