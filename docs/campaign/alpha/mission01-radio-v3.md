# ОПЕРАЦИЯ «РАЙ»
## Миссия 1 — «Освоение целины»
### Полный сценарий v3 — радиопереговоры, события и тайминги

**Место действия:** песчаные пустоши западнее России.

**Фракции:** группа «Альфа» организации «Рай» и отбросы.

**Формат:** портрет говорящего и радиопереговоры поверх игры. Без остановки камеры, управления, строительства и боя.

**Правило юмора:** одна шутка — максимум три короткие реплики, кроме уже записанных и принципиально важных многосоставных сцен. Герои говорят естественно и серьёзно. Не превращать каждого персонажа в стендап-комика.

# ТАЙМИНГИ И ПРАВИЛА ПРОИГРЫВАНИЯ

## Внутри диалога

- Обычная пауза между репликами: 0,15–0,35 секунды.
- Пауза перед неожиданным ответом: 0,4–0,8 секунды.
- Время реплики: реальная длительность MP3.
- Не добавлять программную паузу поверх уже записанной актёрской паузы.
- Не растягивать речь изменением скорости без необходимости.

## Между сюжетными событиями

Сюжетные сообщения запускаются от игровых событий, а не по абсолютному времени миссии.

Начало первой атаки не должно зависеть от того, сколько разговоров успело прозвучать. Оно должно зависеть от логики миссии и состояния базы.

## Во время походов на лагеря

- При обнаружении важного объекта — короткий разведывательный доклад.
- При захвате артефакта — соответствующий разговор.
- При завершении исследования — сообщение НИИ.
- При длительном спокойном перемещении — редкие бытовые реплики.
- При активном бою — только актуальные боевые сообщения.

Обычные бытовые реплики ограничивать глобальным интервалом примерно 35–60 секунд и дополнительным индивидуальным cooldown для повторяющихся событий.

## Приоритеты

**P0 — срочный бой:** нападение, опасность, критический приказ.

**P1 — важное событие:** исследование, новый объект, выполнение задачи.

**P2 — сюжетный диалог:** короткие разговоры, связанные с текущим этапом миссии.

**P3 — бытовые комментарии:** случайные реплики, ответы на выбор юнита, ремонт и движение.

Срочное сообщение может прервать сценку. Если её смысл после боя потерян — сценку отменить целиком.

Не воспроизводить ответ на вопрос, который игрок не услышал.

## Сохранения

Хранить:

- Завершённые сценки.
- Активные приказы и цели.
- Уже обнаруженные события.
- Текущее состояние сценарного планировщика.
- Прерванные, пропущенные и ожидающие разговоры.

После загрузки завершённые диалоги не повторять.

## Изменяемый порядок лагерей

Игрок может зачищать лагеря не по номеру. Артефактные сцены запускаются по обнаружению конкретного объекта, а не по порядковому номеру уничтоженного лагеря.

Сюжетные обозначения «первый», «второй», «третий» используются как авторский порядок, но система не должна выдавать ложные сообщения при альтернативном маршруте.

# СОХРАНЕНИЕ ГОТОВОЙ ОЗВУЧКИ

Исходные аудиофайлы не удалять и не перезаписывать.

**[Т]** — сохранить исходный ID и точный текст.

**[В]** — временная озвучка, пригодность проверить при интеграции.

**[Н]** — новая реплика, нужен новый уникальный ID и отдельная запись.

Не назначать старый MP3 новой реплике с похожим, но другим текстом.

Если реплика исключена из основной очереди, сохранить её в архиве сценарных ресурсов для возможного повторного использования.

В исходной ведомости есть несовпадения между логическими ID реплик и именами MP3. Их необходимо сверить по самим аудиофайлам, а не только по именам и контрольным суммам.

# КРИТЕРИИ ГОТОВНОСТИ

1. Игрок проходит всю миссию без ожидания озвучки.
2. Электростанция логично ведёт к нефтяным вышкам, затем к заводу и НИИ.
3. Первое нападение следует после базового развития, не зависит от окончания бытовых разговоров.
4. После нападения появляется задача укрепить базу ДОТами.
5. В каждом из четырёх лагерей есть собственное игровое событие и радиодиалог.
6. Исследования и технологии не привязаны ошибочно к жёсткому порядку лагерей.
7. Шутки звучат целиком и не теряют смысл из-за длинных пауз.
8. При быстром прохождении используется короткий актуальный вариант сообщения, а не старый диалог.
9. Во время продолжительных походов допускается редкий бытовой эфир без спама.
10. Финальная победа и южный энергетический всплеск работают при любом допустимом порядке прохождения.
11. Все пользовательские MP3 сохраняются независимо от того, вошла ли их реплика в новую редакцию.
